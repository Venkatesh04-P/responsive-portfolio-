# Responsive Personal Portfolio Website

## Project Overview

This project is a responsive personal portfolio website developed using
HTML5, CSS3 and JavaScript.

The website presents the developer's:

- Profile
- About information
- Technical skills
- Projects
- Education
- Experience
- Certifications
- Contact information

The website is designed to work on desktop, tablet and mobile devices.

---

## Objective

The main objective of this project is to learn and implement:

- HTML5 semantic structure
- CSS3 styling
- Responsive web design
- Flexbox
- CSS Grid
- Media queries
- Navigation
- HTML forms
- JavaScript
- Form validation

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git
- GitHub

---

## Features

### Home

Introduces the developer and provides buttons to navigate
to projects and contact sections.

### About

Displays information about the developer, career goals,
strengths and interests.

### Skills

Displays technical skills such as:

- Java
- Python
- HTML5
- CSS3
- JavaScript
- Git & GitHub

### Projects

Displays academic and software projects.

### Education / Experience

Shows the developer's academic journey and practical experience.

### Certifications

Displays certifications, training and achievements.

### Contact

Contains contact information and a contact form.

---

## How to Run

1. Download the project.

2. Open the project folder in VS Code.

3. Open `index.html`.

4. Right-click `index.html`.

5. Select:

   Open with Live Server

Or simply open `index.html` directly in a browser.
